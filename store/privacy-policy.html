nlogn Privacy Policy

Last updated:

nlogn is a browser extension for LeetCode. This policy explains what data it handles and where it goes. The short version: nlogn has no backend server. There is nowhere for your code or API key to go except from your own browser directly to the AI provider you choose.

What nlogn stores

The following are stored only in your browser, using chrome.storage.local (not synced to your Google account or any other device):

  • Your chosen AI provider and model
  • Your API key for that provider
  • General settings

This data never leaves your device except as described below.

What nlogn sends, and to whom

When you click Analyze, or when a LeetCode submission completes, nlogn sends the following directly from your browser to the AI provider you configured (Gemini, DeepSeek, OpenAI, or Anthropic — whichever one you picked):

  • Your solution code for the current problem
  • Structural facts extracted from parsing that code (loop/recursion/library-call information)
  • The problem's title, difficulty, and description, fetched from LeetCode's own GraphQL API using your existing LeetCode session
  • For submission diagnostics: the verdict LeetCode returned (e.g. Wrong Answer, Time Limit Exceeded), including the failing test input and expected/actual output where LeetCode provides them

This is sent using the API key you provided, under whatever data-handling terms that provider publishes. nlogn does not operate any server that receives, logs, or stores this data — it goes directly from your browser to theirs.

What nlogn does not do

  • No account, no sign-up, no analytics, no tracking
  • No access to LeetCode Premium content — nlogn only ever sees what your own LeetCode session can already see
  • No selling or sharing of data, because there is no data collected to sell

Third-party AI providers

When you use nlogn, you are also subject to the privacy policy and terms of whichever AI provider you've configured:

  • Google (Gemini)
  • DeepSeek
  • OpenAI
  • Anthropic

nlogn has no control over, and is not responsible for, how those providers handle data you send them.

Changes to this policy

If this policy changes, the updated version will be published at this same URL with a new "last updated" date.
